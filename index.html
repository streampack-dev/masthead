bytecode.news mastheads

Each animation that can run behind the bytecode.news masthead, at full strength. The sites show them faintly behind the name; the strength slider shows them that way too. Source and how to use them: streampack-dev/masthead.

Your system asks for reduced motion, so the mastheads are left blank, as the sites leave them.

MIT licensed. Add ?ambientDebug=1 to log each choice.
